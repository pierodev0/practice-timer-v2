# Music Practice Routine

App for tracking music practice: named routines of exercises, live practice runs, and stat history with multi-device sync.

## Practice

**Routine**:
A named practice template: an ordered set of exercises to work through.
_Avoid_: playlist, workout.

**Exercise**:
A single practice unit inside a routine, with its own behavior and targets.
_Avoid_: task.

**Practice run**:
A live execution of a routine, from start to finish. Transient; only a completed run becomes a session.
_Avoid_: live session.

**Session**:
The stored record of a completed practice run, with per-exercise snapshots.
_Avoid_: history entry.

## Tracking

**Stat**:
A named measurable tracked over time, such as max tempo.
_Avoid_: metric.

**Log**:
A single dated value recorded for a stat.
_Avoid_: entry.
